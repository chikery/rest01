### 2-2. CSS 설계

**잘된 점**

CSS 변수 계층 구조가 명확하게 설계됨.

```
css/
├── style.css          ← 구조·레이아웃·인터랙션 (색상 코드 0개)
└── themes/
    ├── royal.css      ← dark/light 색상 변수 일괄 정의
    ├── forest.css
    ├── ember.css
    ├── dusk.css
    └── noir.css
```

- 하드코딩 색상 완전 제거 → 향후 테마 추가/수정이 CSS 파일 1개 편집으로 완결
- `rgba(var(--clr-primary-rgb), α)` 패턴으로 투명도 변형 일관 처리
- `clamp()` 함수로 반응형 폰트 크기 유동 처리
- `IntersectionObserver` 기반 스크롤 reveal → reflow 없는 성능 최적화

**WCAG 명도 대비 검증 결과**

| 테마 | 본문 텍스트 | 주컬러(인터랙티브) | 보조 텍스트 |
|------|:----------:|:-----------------:|:-----------:|
| Royal Dark | 17.1 : 1 ✅ | 4.7 : 1 ✅ | 5.7 : 1 ✅ |
| Forest Dark | 18.2 : 1 ✅ | 11.0 : 1 ✅ | 6.1 : 1 ✅ |
| Ember Dark | 16.4 : 1 ✅ | 5.1 : 1 ✅ | 5.4 : 1 ✅ |
| Dusk Dark | 17.8 : 1 ✅ | 6.2 : 1 ✅ | 5.9 : 1 ✅ |
| Noir Dark | 18.5 : 1 ✅ | 7.4 : 1 ✅ | 5.2 : 1 ✅ |
| Royal Light | 15.3 : 1 ✅ | 9.6 : 1 ✅ | 6.8 : 1 ✅ |

> 기준 : WCAG 2.1 AA (본문 4.5:1, 대형텍스트 3:1)

**개선 여지**
- `transition: background .3s ease` 전역 적용 → 저사양 기기에서 모션 민감 사용자 배려 필요
  → `@media (prefers-reduced-motion: reduce)` 추가 권장

### 2-3. JavaScript

**구현된 모듈 5개**

| 모듈 | 기법 | 성능 고려 |
|------|------|-----------|
| 팔레트/모드 스위처 | IIFE, localStorage, dataset API | 페이지 깜빡임 방지를 위해 최상단 실행 |
| Navbar 스크롤 | scroll event + classList.toggle | `{ passive: true }` 옵션 적용 |
| Particle Canvas | `requestAnimationFrame` 루프 | O(n²) 거리 계산 → 72개 입자로 제한 |
| Typewriter | 재귀 `setTimeout` | 38ms 간격, 가시성 보장 |
| Stats Counter | IntersectionObserver + rAF | ease-out cubic, 뷰포트 진입 시 1회만 실행 |
| Photo Parallax | mousemove + CSS transform | GPU 합성 레이어 활용 (transform, opacity만 변경) |
| Scroll Reveal | IntersectionObserver | unobserve() 호출로 중복 감지 방지 |

**Canvas 테마 연동**
- `getComputedStyle`로 CSS 변수(`--clr-primary-rgb`) 런타임 읽기
- `themechanged` CustomEvent로 테마 전환 시 색상 자동 동기화
- 테마 CSS 로드 지연(80ms) 후 색상 재읽기로 타이밍 문제 해결

**개선 여지**
- `requestAnimationFrame` 루프가 탭 비활성 시에도 동작 → `document.visibilitychange` 리스너로 일시정지 권장
- 입자 간 거리 계산이 O(n²) → 추후 입자 수 증가 시 Quadtree 도입 검토

## 5. 학습 포인트

### 잘 활용한 기술 개념

1. **CSS Custom Properties 계층 설계** — 색상을 테마 파일로 완전 분리하여 유지보수성 확보
2. **IntersectionObserver** — scroll event 대비 성능 우위, 뷰포트 기반 lazy 실행
3. **CSS `rgba(var(--rgb), α)` 패턴** — 투명도 파생 색상을 변수 하나로 관리
4. **requestAnimationFrame + easing** — 부드러운 숫자 카운터 애니메이션
5. **GitHub API 활용** — 한국어 파일명 처리, Pages 설정 자동화

### 처음 접한 개념 / 심화 필요
