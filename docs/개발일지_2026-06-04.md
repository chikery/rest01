### 2-4. Hero 영역 JavaScript 인터랙션 효과

**① Particle Network Canvas**
- `<canvas>` 태그를 Hero 섹션 배경에 삽입
- 72개 입자(particle)가 랜덤 속도로 부유
- 인접 입자(140px 이내) 간 연결선 렌더링 (거리 비례 투명도)
- 마우스 접근 시 90px 반경 내 입자 반발(repulsion) 효과

**② Typewriter Effect**
- `typingText` 스팬에 38ms 간격으로 한 글자씩 삽입
- "AI 엔지니어" 키워드는 `<strong>` 태그로 볼드 처리
- 커서 깜빡임 CSS 애니메이션 (`step-end`, 0.75s)

**③ Stats Counter Animation**
- `data-target`, `data-prefix`, `data-suffix` 속성으로 목표값 지정
- IntersectionObserver로 뷰포트 진입 시 카운트 시작
- ease-out cubic 이징 함수 적용 (1400ms)

**④ Photo Parallax**
- 마우스 X/Y 위치를 Hero 중앙 기준 정규화 (-1 ~ 1)
- 사진 래퍼 : `translate(dx*8px, dy*6px)`
- Glow 1 : 반대 방향 `translate(-18px, -12px)` 배율
- Glow 2 : 동방향 `translate(+12px, +10px)` 배율

### 2-5. 컬러 팔레트 시스템 구축

**설계 원칙**
- 주컬러 : 로열 블루
- 보조 컬러 : 로열 블루 50% 투명도 (`rgba(var(--clr-primary-rgb), 0.5)`)
- 이벤트 컬러 : 베이비 블루
- 전체 WCAG AA 명도 대비 기준(4.5:1) 준수

**5가지 컬러 팔레트**

| 이름 | 다크 배경 | 주컬러 | 이벤트 컬러 |
|------|----------|--------|------------|
| 🌊 Royal | `#070A1A` | `#3D6FE8` | `#93C5FD` |
| 🌿 Forest | `#060F09` | `#34D399` | `#BEF264` |
| 🔥 Ember | `#100707` | `#F87171` | `#FCA5A5` |
| 🌙 Dusk | `#08060F` | `#A78BFA` | `#C4B5FD` |
| ⭐ Noir | `#09090A` | `#F59E0B` | `#FDE68A` |

**CSS 아키텍처**

```
css/
├── style.css          ← 구조/레이아웃만, 색상 변수 없음
└── themes/
    ├── royal.css      ← [data-mode="dark"] + [data-mode="light"] 변수
    ├── forest.css
    ├── ember.css
    ├── dusk.css
    └── noir.css
```

- `<html data-mode="dark" data-theme="royal">` 속성으로 현재 상태 관리
- `localStorage`에 테마/모드 저장 → 재방문 시 유지

**라이트 모드 대응**
- 각 테마 파일에 `[data-mode="light"]` 셀렉터로 밝은 색상 세트 정의
- 라이트 모드에서 어두운 배경 요소(nav 오버레이, canvas 투명도, glow 강도) 별도 조정

**팔레트 위젯 UI**
- 우하단 고정 `🎨` 버튼 → 패널 슬라이드 오픈
- 다크/라이트 토글 버튼 (pill 형태)
- 5개 스와치 (어두운 반 + 밝은 반 분할 정사각형)
- 패널 외부 클릭 시 자동 닫힘
